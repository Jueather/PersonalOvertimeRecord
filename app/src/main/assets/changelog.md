# 更新日志

## [0.2.1] - 2026-10-24

### 新增
- 节假日在线更新：新增仓库固定数据源 `holiday/holidays.json` 与 `HolidayStore`；设置页「节假日数据」卡片可手动检查更新，在线数据按日期覆盖内置数据（未覆盖部分继续使用内置），校验通过后写入本地缓存，应用启动时注入、离线可用；更新失败仅提示，不影响现有计算
- 系统日历双向同步：新增 `CalendarSyncManager`，加班/请假记录写成系统日历全天日程（标题携带工时/倍率/请假类型，描述带识别标记）；同步时回写日历侧的时长修改、改期与删除，以每条记录的 `syncedAt` 做最后写入者优先；设置页新增「日历同步」卡片与按需权限申请
- 数据库 8→9：新增 `calendar_links` 映射表（日期 ↔ 日历事件 ID），仅存本机，不参与 WebDAV/团队同步
- 新增权限 `READ_CALENDAR` / `WRITE_CALENDAR`

### 修复
- 日历同步：目标日历变更（新增账号/系统主日历变化）时不再把旧日历事件误判为"已删除"并软删除全部本地记录，改为保留映射并在推送阶段迁移到新日历
- 日历同步：改期/导入前按"含软删除记录"判断目标日期是否占用，避免 REPLACE 覆盖软删除墓碑导致该日期被云端同步"复活"

### 改进
- 节假日在线更新增加备用数据源：主源 `raw.githubusercontent.com` 下载失败时自动依次尝试 jsDelivr（cdn/fastly/gcore）镜像，避免部分网络环境下恒为超时；单源超时缩短为连接 5s / 读取 7s，失败提示会带上具体原因

## [0.2.0] - 2026-10-24

### 新增
- 白班/夜班标记：录入对话框可切换班次（默认白班），列表夜班角标，本月统计按班次拆分
- 应用内"修改日志"入口：设置页离线查看各版本更新内容

### 修复
- WebDAV 同步上传丢失自定义工资倍率（customRate）

### 改进
- 录入表单与同步/恢复统一接入输入校验：非法日期、时长、倍率等拦截提示；同步恢复时非法记录跳过并计数
- 录入表单新增未来日期拦截
